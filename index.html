⚙ 设置

🔑 高德地图 Key

用于「自动识别街道」和「搜索地图地点」。已内置默认 Key，开箱即用，无需填写。申请自己的：高德开放平台 → 创建应用 → 添加 Key（服务平台选「Web 服务」）。
自定义 Key 仅保存在本机浏览器；导出 HTML 时内置的默认 Key 会被自动抹掉，不随文件分享。

🛰 天地图 Key

用于「天地图影像 / 地形 / 矢量」三类底图（国家测绘官方，WGS-84 坐标，无偏移）。已内置默认 Key，开箱即用，留空即可。如需用自己的 Key：天地图 → 注册 → 创建应用（类型选「浏览器端」）→ 复制 tk，填下方即可（仅存本机）。
