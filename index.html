🔑 高德地图 Key

用于「自动识别街道」和「搜索地图地点」。申请：高德开放平台 → 创建应用 → 添加 Key（服务平台选「Web 服务」）。Key 仅保存在本机浏览器，不随工程文件分享。

🛰 天地图 Key

用于「天地图影像 / 地形 / 矢量」三类底图（国家测绘官方，WGS-84 坐标，无偏移）。申请：天地图 → 注册 → 创建应用（类型选「浏览器端」）→ 复制 tk。Key 仅保存在本机浏览器。
